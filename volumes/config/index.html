🎓 Web4Student

Ambiente di Sviluppo Linux Completo per Studenti

🏗️ Infrastruttura Tecnica 🟢 ONLINE

🖥️ Sistema Linux Completo

Distribuzione Ubuntu minimale ottimizzata per l'apprendimento della programmazione con accesso SSH completo e strumenti di sistema.

🌐 Server Web Integrato

Apache con supporto PHP per lo sviluppo web. Ogni studente ha la propria directory web accessibile tramite URL personalizzato.

🗄️ Database MySQL/MariaDB con Adminer

Database completo con accesso amministrativo e database personali per ogni studente. Include Adminer per gestione web-based dei database.

🔧 Accesso ad Adminer:

  • Globale: https://w4s.filippobilardo.it/adminer.php
  • Personale: https://w4s.filippobilardo.it/~username/adminer.php
  • Server: localhost | Username: username | Database: db_username

👥 Gestione Utenti Avanzata

Sistema di account multipli con home directory isolate e permessi di sicurezza. Creazione automatica da file CSV.

  • Database Personale: db_username
  • Adminer Personale: ~/adminer.php (gestione database)
  • Password Iniziale: stud123 (da cambiare!)

🚀 Primo Accesso

  1. Connettiti via SSH: ssh username@163.192.115.36 -p 2222
  2. Cambia la password: passwd
  3. Esplora il sistema: ls -la
  4. Directory web: cd ~/www
  5. Modifica il sito: nano index.html
  6. Gestisci database: Accedi ad Adminer tramite ~/adminer.php
